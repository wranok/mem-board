# Mem Board

Нативная Linux-программа на Rust для быстрого поиска и копирования стикеров из локальной папки. По духу это picker наподобие Emote, только содержимое задаёте вы сами.

## Что умеет

- Выбрать папку со стикерами и запомнить её.
- Показать вложенные папки отдельными вкладками; в каждой вкладке — стикеры из неё и её вложенных каталогов.
- Показать общий список «Все» и отдельную вкладку «Корень» для файлов прямо в выбранной папке.
- Найти PNG, JPEG, WebP, GIF и BMP.
- Искать по имени файла.
- Скопировать изображение в системный буфер обмена одним кликом — работает в сессиях Wayland и X11.
- Открыть «Последние стикеры», чтобы повторно скопировать недавние изображения, или очистить эту историю.
- В настройках включить «Закрыть при копировании». Окно скроется, сохраняя владельца Wayland-буфера до вставки.

## Запуск

Требуются Rust, GTK 4 (не ниже 4.22) и libadwaita (не ниже 1.9), включая development-пакеты.

```bash
cargo run --release
```

Для установки бинарника выполните `cargo install --path .`; затем скопируйте desktop-файл в `~/.local/share/applications/`.

На Debian/Ubuntu при необходимости:

```bash
sudo apt install build-essential pkg-config libgtk-4-dev libadwaita-1-dev
```

Настройка хранится в `~/.config/mem-board/settings.json`.
